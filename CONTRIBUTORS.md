### Como Ser Listado Aqui / How to Be Listed Here

Contribuidores que fizerem contribuições significativas ao projeto serão adicionados automaticamente a esta lista. Contribuições significativas incluem, mas não estão limitadas a:

Contributors who make significant contributions to the project will be automatically added to this list. Significant contributions include, but are not limited to:

- **Código / Code**: Novas funcionalidades, correções de bugs, melhorias de performance / New features, bug fixes, performance improvements
- **Documentação / Documentation**: Guias, tutoriais, exemplos, traduções / Guides, tutorials, examples, translations
- **Testes / Testing**: Casos de teste, validação de hardware, reportes de bugs detalhados / Test cases, hardware validation, detailed bug reports
- **Design / Design**: Interface, diagramas, esquemáticos / Interface, diagrams, schematics
- **Suporte / Support**: Ajuda a outros usuários, respostas em issues / Helping other users, answering issues

When you contribute, your name will be added here in the following format:
